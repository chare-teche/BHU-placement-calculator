# BHU Placement Score Calculator

A free web app that helps Bule Hora University freshman students estimate
their department placement score using the university's formula:

- 50% Cumulative GPA (out of 4.0)
- 20% University entrance exam (out of 600)
- 30% COC score (out of 30)

It also shows how competitive the student's score looks against a sample
list of departments and their intake capacity, so students understand their
options before choosing department preferences.

## How to publish this for free with GitHub Pages

1. **Create a free GitHub account** at https://github.com if you don't have one.
2. Click the **+** icon (top right) → **New repository**.
   - Name it something like `bhu-placement-calculator`.
   - Set it to **Public**.
   - Click **Create repository**.
3. On the new repository page, click **uploading an existing file**.
4. Drag in the `index.html` file from this folder (and this `README.md` if you like).
5. Scroll down and click **Commit changes**.
6. Go to the repository's **Settings** tab → **Pages** (in the left sidebar).
7. Under "Build and deployment", set **Source** to **Deploy from a branch**,
   choose branch **main** and folder **/(root)**, then click **Save**.
8. Wait about 1 minute, then refresh the page. GitHub will show your live link
   at the top, in the form:
   `https://<your-github-username>.github.io/bhu-placement-calculator/`
9. Open that link to confirm it works, then share it with the admin office
   or with other students.

## Editing later

To update the app (for example, once the registrar gives you real cut-off
scores instead of the estimates in this version), edit `index.html` directly
on GitHub (pencil icon) or re-upload a new version, then commit — the live
page updates automatically within a minute.

## Notes for the admin office

This tool applies the university's own published 50/20/30 weighting. The
department "chance" labels are estimates based on typical intake sizes, not
official cut-off data. Real cut-off scores from the registrar could be added
to make the tool officially accurate — this was built as a demonstration of
what is possible, and as a genuinely useful tool for future students.
